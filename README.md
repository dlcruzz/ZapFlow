## A história por trás do ZapFlow

> Era mais uma segunda-feira. João tinha uma lista com 200 clientes para contatar. Abriu o WhatsApp, copiou a mensagem, foi no primeiro contato, colou, trocou o nome manualmente, enviou. Depois o segundo. Depois o terceiro...
>
> Duas horas depois, João estava no contato número 47, com dor no pulso e a sensação de que estava desperdiçando o dia inteiro fazendo algo que deveria ser simples.
>
> **Foi aí que nasceu o ZapFlow.**
>
> Hoje João abre o app, cola sua lista, clica em **INICIAR** — e em vez de passar o dia colando mensagem, ele passa o dia fechando negócio. O ZapFlow faz o trabalho chato. João faz o trabalho que importa.

---

## O que é o ZapFlow?

> Imagina ter um assistente que envia mensagens personalizadas para centenas de pessoas no WhatsApp — **cada uma pelo nome**, na hora certa, com o delay certo, sem você precisar tocar no celular. Esse assistente é o ZapFlow.

Você define a mensagem, carrega a lista de contatos, clica em **INICIAR** — e vai tomar um café enquanto tudo acontece automaticamente. ☕

---

## ✨ O que ele faz

| Funcionalidade | Detalhe |
|---|---|
| 💬 **Mensagens personalizadas** | Use `{nome}` e cada pessoa recebe a mensagem com o nome dela |
| 🖼️ **Envio com imagem** | Escolhe uma foto e ela vai junto antes dos textos |
| 👁️ **Prévia estilo WhatsApp** | Veja exatamente como a mensagem vai aparecer antes de enviar |
| ⏱️ **Delay inteligente** | Define delay fixo ou aleatório entre mensagens para parecer mais humano |
| ⏳ **Estimativa de tempo** | Mostra quanto tempo vai demorar antes mesmo de começar |
| 📊 **Painel em tempo real** | Acompanha enviados, falhas e pendentes ao vivo |
| 📁 **Importa lista CSV** | Carrega centenas de contatos de uma vez |
| 📄 **Relatório de envio** | Exporta um resumo completo do que foi enviado |
| ⏸️ **Pausar e retomar** | Pausa o envio quando quiser e continua de onde parou |

## 🚀 Como instalar (é fácil, prometo)

### Passo 1 — Baixe o instalador

Pegue o arquivo `ZapFlow_Setup.exe` e dê um **duplo clique**.

### Passo 2 — Instale normalmente

```
Próximo → Próximo → Instalar → Concluir
```

Pronto. O ZapFlow vai aparecer na sua Área de Trabalho e no Menu Iniciar.

### Passo 3 — Abra o WhatsApp Desktop

O ZapFlow controla o WhatsApp que já está instalado no seu computador. Então antes de usar, abra o WhatsApp Desktop e certifique-se de que está logado.

### Passo 4 — Mande ver! 🔥

Abra o ZapFlow, configure suas mensagens e clique em **INICIAR ENVIO**.

## 📋 Formato da lista de contatos

O arquivo `contatos.csv` é simples assim:

```csv
nome,telefone
Maria Silva,5511999999999
João Pedro,5511888888888
Carlos,5521977777777
```

Pode criar no Excel, Google Sheets ou até no Bloco de Notas. Salva como `.csv` e importa no app.

> **Dica:** Números brasileiros podem ser colocados sem o 55 — o ZapFlow adiciona automaticamente.

---

## ⏱️ O delay — por que ele importa?

Enviar mensagens muito rápido pode parecer spam para o WhatsApp. O ZapFlow tem dois modos:

- **Fixo** → sempre espera X segundos entre cada mensagem
- **Aleatório** → sorteia um tempo entre X e Y segundos (parece mais humano!)

O padrão recomendado é **aleatório entre 4 e 90 segundos**. Assim o envio parece natural e você não corre risco de bloqueio.

## 🛠️ Para desenvolvedores

<details>
<summary>Clique aqui para ver como rodar o projeto via Python</summary>

**1. Clone o repositório e crie o ambiente virtual**
```powershell
git clone https://github.com/dlcruzz/ZapFlow.git
cd ZapFlow
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

**2. Rode o app**
```powershell
python panel_app.py
```

**3. Gerar o .exe**
```powershell
pyinstaller --onefile --windowed --icon=img/zapflow.ico --name=ZapFlow --add-data "img;img" --add-data "config.py;." panel_app.py
```

**4. Gerar o instalador** (requer [Inno Setup](https://jrsoftware.org/isinfo.php))
```powershell
ISCC.exe installer.iss
```

```
├── contatos.csv          ← Lista de contatos

│   ├── zapflow.png

```
