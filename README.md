## A história por trás do ZapFlow

> Era mais uma segunda-feira. João tinha uma lista com 200 clientes para contatar. Abriu o WhatsApp, copiou a mensagem, foi no primeiro contato, colou, trocou o nome manualmente, enviou. Depois o segundo. Depois o terceiro...
>
> Duas horas depois, João estava no contato número 47, com dor no pulso e a sensação de que estava desperdiçando o dia inteiro fazendo algo que deveria ser simples.
>
> **Foi aí que nasceu o ZapFlow.**
>
> Hoje João abre o app, cola sua lista, clica em **INICIAR** — e em vez de passar o dia colando mensagem, ele passa o dia fechando negócio. O ZapFlow faz o trabalho chato. João faz o trabalho que importa.

---

## O que é o ZapFlow?

> Um assistente que envia mensagens personalizadas para centenas de pessoas no **WhatsApp** e no **Instagram** — cada uma pelo nome, na hora certa, com o delay certo, sem você precisar tocar em nada. Dois canais, um app.

---

## ✨ O que ele faz

### WhatsApp
| Funcionalidade | Detalhe |
|---|---|
| 💬 **Mensagens personalizadas** | Use `{nome}` e cada pessoa recebe com o nome dela |
| 🖼️ **Envio com imagem** | Foto vai junto antes dos textos |
| 👁️ **Prévia estilo WhatsApp** | Veja como vai aparecer antes de enviar |
| ⏱️ **Delay inteligente** | Fixo ou aleatório entre mensagens |
| ⏳ **Estimativa de tempo** | Mostra quanto vai demorar antes de começar |
| 📊 **Painel em tempo real** | Enviados, falhas e pendentes ao vivo |
| 📁 **Importa CSV ou cola em massa** | Centenas de contatos em segundos |
| 📄 **Relatório de envio** | Exporta resumo completo |
| ⏸️ **Pausar e retomar** | Controle total do envio |

### Instagram DM
| Funcionalidade | Detalhe |
|---|---|
| 📸 **DM automático** | Envia mensagens diretas pelo app do Instagram para Windows |
| 🔍 **Busca automática** | Pesquisa cada `@username`, entra no perfil e abre o DM |
| 🖱️ **Detecção visual do botão** | Localiza o botão "Enviar mensagem" por scan de pixels, sem depender de coordenadas fixas |
| ✅ **Confirmação por screenshot** | Verifica se o modal de DM abriu antes de digitar |
| ⌨️ **Digitação humana** | Escreve letra por letra com velocidade variável para não ser detectado como bot |
| 🔄 **Reset entre contatos** | Volta ao feed entre cada envio para garantir estado limpo |
| ⏱️ **Delays anti-bloqueio** | 15–35s entre contatos, 4–10s entre mensagens |

### Proteção Anti-Bloqueio (ambos os canais)
| Funcionalidade | Detalhe |
|---|---|
| 🛡️ **Limite diário** | Define máximo de envios por dia |
| 📈 **Modo aquecimento** | Começa com 10/dia e aumenta automaticamente |
| 🕐 **Horário humanizado** | Só envia entre os horários configurados |
| ⚡ **Spin text** | `[opção1/opção2]` — cada contato recebe variação diferente |
| 🎭 **Perfis de digitação** | Lenta / Média / Rápida / Aleatório |
| 🔄 **Sessões separadas** | Divide envios em blocos com pausa entre eles |

## 🚀 Como instalar

### Passo 1 — Baixe o instalador
Pegue o arquivo `ZapFlow_Setup.exe` e dê um **duplo clique**.

### Passo 2 — Instale normalmente
```
Próximo → Próximo → Instalar → Concluir
```

### Passo 3 — Requisitos antes de usar

**Para WhatsApp:**
- Abra o **WhatsApp Desktop** e confirme que está logado

**Para Instagram:**
- Instale o **app do Instagram para Windows** (Microsoft Store — gratuito)
- Abra o app e confirme que está logado na sua conta

### Passo 4 — Mande ver!
Abra o ZapFlow, configure as mensagens e clique em **INICIAR ENVIO**.

---

## 🗺️ Como usar — WhatsApp

```
Passo 1 — Mensagens
  Escreva os blocos de mensagem (cada bloco = 1 msg separada)
  Use {nome} para personalizar  |  Use [op1/op2] para variar
  Adicione imagem se quiser     |  Clique em "Ver Prévia"
  Salve as mensagens

Passo 2 — Contatos
  Cole nomes e telefones direto do Excel (um por linha)
  Ou carregue um arquivo CSV

Passo 3 — Envio
  Configure delays e proteções anti-bloqueio
  Clique em INICIAR ENVIO
  Acompanhe o progresso em tempo real
```

---

## 🗺️ Como usar — Instagram DM

```
Aba Instagram DM
  Cole os @usernames dos perfis (um por linha)
  Configure as mensagens (mesmas do WhatsApp ou diferentes)
  Clique em INICIAR INSTAGRAM

O bot faz automaticamente para cada contato:
  1. Abre o app do Instagram
  2. Clica na lupa e pesquisa o @username
  3. Entra no perfil (primeiro resultado)
  4. Localiza e clica em "Enviar mensagem" por detecção visual
  5. Verifica se o modal de chat abriu
  6. Clica no campo de texto e digita as mensagens
  7. Volta ao feed e passa para o próximo
```

> O Instagram deve estar **instalado pelo Microsoft Store** e você deve estar **logado na conta** antes de iniciar.

## 📋 Formato da lista de contatos (WhatsApp)

```csv
nome,telefone
Maria Silva,5511999999999
João Pedro,5511888888888
Carlos,5521977777777
```

> Números brasileiros podem ser colocados sem o 55 — o ZapFlow adiciona automaticamente.

## 📦 Para quem vai vender ou distribuir

Só manda o arquivo `ZapFlow_Setup.exe` para o cliente.

Ele instala, abre e já está pronto para usar. Nada de Python, nada de terminal, nada de configuração técnica.

## ⚠️ Requisitos mínimos

- Windows 10 ou 11
- WhatsApp Desktop instalado e com sessão ativa (para envios via WhatsApp)
- App do Instagram (Microsoft Store) instalado e logado (para envios via Instagram)
- Conexão com a internet

## 🛠️ Para desenvolvedores

<details>
<summary>Clique aqui para ver como rodar o projeto via Python</summary>

**1. Clone o repositório e crie o ambiente virtual**
```powershell
git clone https://github.com/dlcruzz/ZapFlow.git
cd ZapFlow
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

**2. Rode o app**
```powershell
python panel_app.py
```

**3. Gerar o .exe**
```powershell
pyinstaller --onefile --windowed --icon=img/zapflow.ico --name=ZapFlow `
  --add-data "img;img" --add-data "config.py;." `
  --add-data "anti_ban.py;." --add-data "theme.py;." `
  --add-data "instagram_sender.py;." panel_app.py
```

**4. Gerar o instalador** (requer [Inno Setup](https://jrsoftware.org/isinfo.php))
```powershell
ISCC.exe installer.iss
```

**Estrutura do projeto:**
```
ZapFlow/
├── panel_app.py           ← Painel visual principal (customtkinter)
├── whatsapp_sender.py     ← Motor de automação do WhatsApp Desktop

├── anti_ban.py            ← Proteções anti-bloqueio (spin text, warm-up, etc.)
├── config.py              ← Mensagens padrão e configurações
├── theme.py               ← Design system (cores, fontes, espaçamentos)
├── icons.py               ← Ícones vetoriais gerados com PIL
├── messages.json          ← Mensagens salvas pelo usuário
├── contatos.csv           ← Lista de contatos WhatsApp
├── img/
│   ├── zapflow.png
│   └── zapflow.ico
└── requirements.txt
```
